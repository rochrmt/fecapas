# FECAPAS-RCA

Site vitrine statique de l’Association des Femmes Courageuses en Action pour la Paix et la Sécurité.

## Lancer le site

```bash
python3 -m http.server 4173
```

Ouvrir ensuite `http://localhost:4173`.

## Structure

- `index.html` : contenu et structure de la page
- `styles.css` : identité visuelle et responsive
- `script.js` : navigation mobile et animations d’apparition
- `assets/images` : logo et médias publics de FECAPAS
